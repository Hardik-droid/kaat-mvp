KAAT demonstration

KAAT-demo.mp4 is an actual Windows screen recording of native mouse/keyboard actions and media playback. It is silent; no microphone or generated narration is included. KAAT-original-sample.mp4 and KAAT-edited-sample.mp4 retain the human speech audio.

The demo shows actual filler analysis, which returned zero confident filler suggestions on this sample. It does not claim successful filler removal. Actual long-pause suggestions are approved, undone, approved again, and exported as a playable copy. See demo-evidence.json for verified durations and source hash.

Sample attribution: public human Hindi-English lecture speech from OpenSLR 104 (CC BY-SA 4.0), https://www.openslr.org/104/ ; dataset mirror https://huggingface.co/datasets/dianavdavidson/MUCS-Hinglish . The source video uses a generated test-pattern picture and an inserted silence gap with that real speech; speech is not synthesized.
