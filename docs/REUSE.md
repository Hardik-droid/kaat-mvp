# Open-source review and attribution

Reviewed on **10 November 2026** using the public GitHub repositories, their README files, dependency manifests and license files. All seven requested repositories were publicly accessible. Commit IDs below identify the reviewed snapshots; later upstream changes may differ.

KAAT extends its existing Python/Tkinter/FFmpeg starter. No source from another editor was copied. Existing FFmpeg silence detection and Python's `difflib.SequenceMatcher` cover this MVP without importing several editing pipelines or downloading speech models. Gnani remains the primary speech provider.

The reviewed editors' permissive top-level licenses do not override their dependencies' or model weights' terms. No proprietary competitor source or noncommercial-licensed editor code was incorporated.
